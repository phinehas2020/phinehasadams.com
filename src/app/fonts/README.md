# Local font

Site Sans is a WOFF2 conversion of Liberation Sans Regular and Bold, with unchanged glyph outlines and metrics. The primary font names were changed because the source license reserves the Liberation name for modified versions, including format conversions.

Source: https://github.com/liberationfonts/liberation-fonts

Copyright notices and the SIL Open Font License 1.1 are retained in `LICENSE.txt` and the fonts' metadata. The fonts remain under that license. They are served locally through `next/font/local`.

Cover Sans is a WOFF2 conversion of the open-source Archivo variable font, renamed for the site. Its original width and weight axes provide the heavier publication headings; no glyph outlines were changed. Source: https://github.com/google/fonts/tree/main/ofl/archivo . Its separate SIL Open Font License is retained in `CoverSans-LICENSE.txt` and the font metadata.
