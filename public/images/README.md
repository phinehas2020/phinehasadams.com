# Apollo 17 Earthrise

`apollo17-earthrise.jpg` is the original NASA archive photograph AS17-152-23272, photographed in lunar orbit during Apollo 17 in December 1972.

- Archive item: https://images.nasa.gov/details/as17-152-23272
- Original file: https://images-assets.nasa.gov/image/as17-152-23272/as17-152-23272~orig.jpg

The site credits NASA and links to the archive. The photograph is visual inspiration, not portfolio evidence or an affiliation claim. The original is preserved; the displayed crop is set in `Hero.module.css`.
